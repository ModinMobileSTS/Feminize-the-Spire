# Feminize the Spire

此模组旨在解决 anaertailin 的娘化系列模组分发混乱的问题，本模组收录了截至 2026.5.15 的所有的a大发布的原版娘化模组，包括 MonsterFeminization、NpcFeminization、FeminizationMod 和 ExtraFeminizationMod 中所有的美术资源，并解决了若干冲突问题和性能/内存泄露问题

支持a大谢谢喵：https://www.afdian.com/album/c125877626ff11eea47652540025c377

同时启用独立的 Merchant Feminization（商人娘化）时，商人外观和商店手部贴图以该模组的设置为准。需另行安装，本模组不内置其资源。
